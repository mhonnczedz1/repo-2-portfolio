# images/

Drop screenshots here. Any file that is missing prints as a dashed box showing its expected
name, so a half-finished overview still lays out correctly.

| Name | What it holds |
|---|---|
| `01-<slug>.png` | first screenshot |
| `02-<slug>.png` | second screenshot |
| `03-<slug>.png` | third, only if it earns the space |
| `architecture.png` | optional, only when the CSS diagram kit cannot express the topology |

Around 1200px wide crops well into the two-column grid. Filenames in the HTML must match
exactly, including case.
